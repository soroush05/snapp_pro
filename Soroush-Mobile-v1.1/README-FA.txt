Soroush Mobile v1.0 — Android-first personal agent

هدف این بسته:
- Android: اجرای واقعی فرمان روی اپ Snapp از طریق AccessibilityService
- Web/Laptop: نسخه همراه برای مدیریت/آزمایش منطق قبلی
- iOS: به دلیل محدودیت سیستم‌عامل، بدون API رسمی Snapp امکان کنترل کامل اپ دیگر مانند Android وجود ندارد.

قابلیت Android در این نسخه:
1) فهم فرمان‌های فارسی ساده و طبیعی برای سفر
2) جست‌وجوی Saved Places قبل از هر جست‌وجوی عمومی
3) «پیش علی» -> ابتدا موقعیت ذخیره‌شده علی
4) «میخوام برم آرایشگاه» -> ابتدا Saved Places؛ اگر ذخیره نیست، آدرس می‌خواهد
5) افزودن موقعیت: شهر -> عنوان -> آدرس
6) درخواست Snapp بعد از تایید کاربر
7) لغو سفر Snapp بعد از تایید
8) پرداخت از کیف پول Snapp بعد از تایید
9) عنوان «پرداخت خودکار» بدون توضیح اضافه
10) توقف امن اگر UI مورد انتظار Snapp پیدا نشود؛ برنامه کلیک کور انجام نمی‌دهد.

نصب/Build Android:
- Android Studio را نصب کن.
- پوشه android را Open کن.
- Gradle Sync را انجام بده.
- Build > Build APK(s)
- APK را روی گوشی Android که Snapp روی آن نصب است نصب کن.
- داخل Soroush Agent روی «دسترسی Snapp» بزن.
- در Accessibility Settings سرویس Soroush Agent را فعال کن.

تست پیشنهادی:
1) یک موقعیت با عنوان «علی» ذخیره کن.
2) بگو: «یه اسنپ بگیر برم پیش علی»
3) وقتی Agent مقصد را نشان داد، بگو: «تایید»
4) Snapp باز می‌شود و Agent تلاش می‌کند مقصد و Request Ride را از UI واقعی Snapp اجرا کند.
5) برای لغو: «سفر رو لغو کن» سپس «تایید»
6) برای پرداخت: «هزینه رو پرداخت کن» سپس «تایید»

محدودیت مهم:
این پروژه از API خصوصی/توکن استخراج‌شده Snapp استفاده نمی‌کند. اتصال Android با UI خود Snapp انجام می‌شود. چون UI Snapp ممکن است بین نسخه‌ها تغییر کند، اولین تست روی گوشی واقعی تعیین می‌کند آیا selectorهای فعلی با نسخه نصب‌شده تو تطابق کامل دارند یا باید متن/مرحله خاص همان نسخه تنظیم شود.

Snapp package candidates:
- cab.snapp.passenger (نسخه‌های جدید)
- cab.snapp.passenger.play (برخی نسخه‌های قدیمی/Play)

امنیت:
- هیچ رمز کارت، CVV2 یا OTP ذخیره نمی‌شود.
- Request Ride، Cancel Ride و Wallet Payment فقط بعد از تایید صریح کاربر اجرا می‌شوند.
