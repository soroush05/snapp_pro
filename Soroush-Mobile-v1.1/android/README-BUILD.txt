Open this folder in Android Studio (Ladybug or newer recommended), let Gradle sync, then Build > Build APK(s).
Install the APK on the Android phone that already has Snapp installed.
In Soroush Agent tap «دسترسی Snapp» and enable the Soroush Agent accessibility service.
Current Snapp package candidates configured: cab.snapp.passenger and cab.snapp.passenger.play.
